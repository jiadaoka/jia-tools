# 契约未经确认不改

契约是别人依赖的那个东西。改它不会立刻报错，会等在某个调用方上炸开。

## 1 什么算契约

接口路径、字段名、枚举取值、返回结构、错误码、默认行为。

判断标准只有一条：**改了它，会不会有人必须跟着改？** 会，它就是契约。

## 2 改之前

1. **列影响面**：谁在用、怎么用、用的是哪一部分。
2. **决定改法**：加字段还是改字段。加字段几乎总是更便宜，改字段要动所有调用方。
3. **同步**：所有调用方在同一次改动里改完，不要留「先合并，稍后补」。

## 3 破坏性变更

接口、数据格式、配置项、部署顺序，任何一项变了都必须显式声明，并说清回滚顺序。声明漏了，出事时没人知道该回滚哪个版本。

## 4 自检

1. 我改的这个东西，有别人依赖吗？列出来了吗？
2. 能不能加字段解决，而不是改字段？
3. 调用方都同步了吗，包括我还没搜到的那些？
4. 破坏性变更声明了吗？
