# 布局默认起点

**骨架在项目的公共样式里铺一次，不是每个页面写一次。** 可粘贴的模板在 `dev-init-project` 技能的 `templates/layouts.scss`；项目里还没有就让那个技能铺（或照它粘一次），不要手写第二份。

页面只负责用类名，页面级组件里不再出现任何骨架代码：

```vue
<div class="layout-wrapper">
  <header class="layout-header">…</header>
  <main class="layout-body">…</main>
  <footer class="layout-footer">…</footer>
</div>
```

**任何布局都先从这里开始。** 页面、弹窗与抽屉里的内容区、需要分子区的卡片——只要能用"上中下"表达，就用这套类名，不要另写 flex。真的不一样（左右分栏、固定侧栏、瀑布流）才叫定制，定制时也只改这一个地方。

**三段结构**：外层纵向 flex；页头页尾 `flex-shrink: 0`，不被内容压扁；主体 `flex-grow: 1` 配 `height: 0`，自己滚。

**头和尾可选，主体不是。** 只有头、只有尾、两头都没有，都是同一个骨架——缺的那段直接不写，不要为此换一套结构，也不要为了对称塞一个空的。

**页尾自带一条上分隔线**（`::after` 一根 1px 线，颜色取项目的线条令牌）。别再给 `layout-footer` 加 `border-top`，也不要为了这条线在页尾里再套一层带边框的容器。

**滚动只允许出现在主体上。** 让整页滚动等于让页头跟着一起跑。那是长文档页面的做法，不是应用页面的做法。

**`height: 0` 是这套骨架的关键一行。** 它让主体的高度由 flex 分配决定，而不是被内容顶开——滚动条因此只出现在主体上。改回 `height: auto` 且没有限高，内容一长就把 wrapper 撑高，滚动跑到整页去。

**高度必须从根往下传。** `height: 100%` 要求父链每一级都有确定高度，中间断一级，主体就塌成内容高度。移动端别用 `100vh`，地址栏伸缩会让它比视区高，用 `100dvh` 或让根节点自己撑满。

**页头页尾是骨架的一部分，不是内容的一部分。** 标题、面包屑、操作按钮放页头，别在主体里又搭一层"伪页头"。

**类名跟着项目走。** 项目里叫 `.page-*` 就继续叫 `.page-*`，三段式的结构不能改。但**别和项目里已有的另一套骨架并存**——两套骨架同时存在时，新页面必须跟着已有的那套走，或者先合并。
