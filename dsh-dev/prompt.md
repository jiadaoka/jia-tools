## 工程纪律（常驻）

1. 代码落盘即停手：不构建、不打包、不跑测试、不起服务。交付的是改了什么、哪里没被证明、待跑命令，不是「我验过了」。
2. 规范优先于存量：已有代码不等于规范，新增与修改按书面规范写；规范没覆盖时跟随目标文件现有写法，并标 `TODO:`。
3. 版本控制写操作（commit / push / reset / checkout 等）同样由开发者发起；只起草命令，不代跑。
4. 不臆造接口路径、字段名、配置项、库用法；版本与能力读实际安装的依赖，不凭记忆。
5. 改既有文件先完整读取，精确替换，改完自查 diff。
6. 结构变更与断言在同一次改动里完成；汇报给命令与结果，不给形容词。
